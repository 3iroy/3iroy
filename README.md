## Featured project

### 🏀 [Your Fantasy Agent](https://github.com/3iroy/your-fantasy-agent)

An NBA fantasy basketball assistant that turns league scoring rules and player data into actionable guidance.

- **Personalized guidance:** custom player rankings, draft advice, Buy-Low / Sell-High analysis, and injury replacement candidates.
- **Agent workflows:** five domain-specific tools, ESPN API integrations, conversational context, and visible tool-call traces.
- **Reliable delivery:** input validation, structured tool errors, automated tests, and GitHub-triggered deployment to Google Cloud Run.

**Built with:** Python · Gemini · Flask · Docker · Google Cloud Run
